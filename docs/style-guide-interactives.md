# Стиль інтерактивів — що беремо з dystosvita

Орієнтир: https://github.com/oksanapas/dystosvita (каталог інтерактивів для 5–11 класів).
Наш каркас (`assets/lesson.js`, вкладки, `data-break`, картка вчителя) лишається; нижче — прийоми, які варто
застосовувати в кожному новому уроці.

## Задум
- Файл починається з одного рядка-коментаря `/* Ідея: … */` — метафора, що тримає весь інтерфейс
  («робочий стіл бюро перевірки: картки-справи, на які ставлять штамп»; «креслярський стіл: 3D-сцена на сітці»).
  Метафора визначає назви кроків, кнопок і звання наприкінці.
- Сюжет і роль для учня: стажер, агент, лаборант. Кроки називаються «Справа 1», «Зміна 2», а не «Завдання 1».

## Механіки, що працюють
- Після кожної відповіді — коротке `why` (1–2 речення), чому саме так. Це головне джерело навчання, не бал.
- «Пастки»: 1–2 пункти, де очевидна відповідь хибна, і `why` пояснює мета-урок («"Учені довели" звучить як факт…»).
- Чесна опція «Не знаю» там, де доречно: 0 балів, без втрат; ставка впевненості (+1/+2/+3 або −1/−2/−3).
- Прогрес: `nav.steps` з ✓ на виконаних кроках, смужка прогресу всередині колоди карток.
- Фінал: звання/ранг + текстовий звіт («Скопіювати звіт», «Почати все спочатку»). Звіт — те, що учень показує вчителю.
- Стан у `localStorage` (ключ із версією, напр. `buro-faktiv-v2`), відновлення після перезавантаження.

## Вигляд
- Токени на `:root`; темна палітра під `@media (prefers-color-scheme: dark)` з `:root:not([data-theme="light"])`
  і дублем у `:root[data-theme="dark"]`; `color-scheme: dark` у темних блоках.
- Шрифти: пара display + body (Unbounded + Golos Text / Onest; JetBrains Mono для коду), `html{font-size:18px}`.
- «Паперові» картки: 2px рамка `var(--ink)` + зсунута тінь `6px 6px 0 var(--line)`; кнопки `.btn` з тінню 3px,
  яка «втискається» при натисканні; штамп-вердикт з анімацією `slam` і `prefers-reduced-motion`.
- `:focus-visible` контрастний; усі клікабельні елементи — справжні `<button>` з `aria-pressed`/`aria-current`.
- Намальовані «сайти/екрани» всередині інтерактиву мають сталі кольори в обох темах (це «картинка»).

## Текст
- Друга особа однини: «Постав штамп», «Знайди джерело». Обидві форми роду: «вигадав чи вигадала».
- Коротко й конкретно; без «натисніть кнопку нижче, щоб…».

## three.js
- Лише коли 3D дає розуміння (ООП-сцена, геометрія). Сцена з `try { new WebGLRenderer } catch { fallback }`,
  підпис «Перетягни сцену, щоб повернути її», решта інтерактиву працює без 3D.
