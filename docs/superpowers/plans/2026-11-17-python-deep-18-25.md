# Поглиблений рівень: Python 18–25 і «Задачник» — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вісім інтерактивних уроків Python (18–25) для курсу `inf10deep` з учительськими картками і розділ «Задачник» з ~60 задачами, які запускаються справжнім Python у браузері й перевіряються на прихованих тестах.

**Architecture:** Спільні модулі `assets/py/` (класичні IIFE на `window.Py.*`, як `assets/boards/*`): чиста логіка (порівняння виводу, підказки до помилок, семантика зрізів/`range`/методів списків, моделі «майже правильних» програм) покрита vitest; `runner.js` керує Web Worker `worker.js`, що вантажить Pyodide з CDN. Задачі — дані `data/taskbook/<тема>.js` з еталонними розв'язками в `taskbook/solutions/`, які звіряє локальний скрипт `npm run check-tasks` через `python3`. Уроки — сторінки в каркасі `assets/lesson.js` + картки `data/teacher-plans.js`.

**Tech Stack:** HTML/CSS/JS без збірки, vitest 5 + jsdom 30, Pyodide `v0.26.4` (jsdelivr), CPython 3 локально для `check-tasks`.

**Spec:** `docs/superpowers/specs/2026-11-17-python-deep-18-25-design.md` (разом із розділом «Уточнення після перевірки будівельником»).

## Review Focus

1. Нескінченний цикл або дуже довга програма учня → через 3 с повідомлення, worker перезапускається, сторінка не зависає (Task 2: тест з фейковим worker, що не відповідає).
2. Учень перезаписує вхідні змінні (`x = 14` у своєму коді) → прихований тест падає з підказкою «не перезаписуй змінні з вхідних даних» (Task 1: `explainMismatch`; Task 7: показ).
3. Учень викликає `input()` → зрозуміле повідомлення, а не зависання (Task 2: worker підміняє `input` функцією, що кидає помилку з українським текстом; тест на протокол).
4. Вивід із кінцевим пробілом / зайвим `\n` / `0.30000000000000004` → перші два зараховуються, третє — ні, але задачі, що друкують `float`, вимагають `round` у умові (Task 1 тести; Task 3 тест структури: задача з `float` у `out` має `round` або `tolerance`).
5. Pyodide не завантажився (`file://`, без мережі, CDN заблоковано) → статус і кнопка «Скопіювати умову й дані»; уроки працюють без нього (Task 2 тест на помилку завантаження; Task 7 і уроки — тест сторінки без worker).
