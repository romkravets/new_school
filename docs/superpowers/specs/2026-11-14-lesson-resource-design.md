# Ресурс підтримки уроку: програми, учительський шар, «відступи» і three.js-сцени

Дата: 2026-11-14
Репозиторій: `new_school` (GitHub Pages, без збірки)

## Навіщо

Зараз сайт — це плаский список вправ для учня: вкладки, вікторина, відповідність, сортування. Три уроки готові. Учитель веде **9 курсів** за різними модельними програмами (8, 9, 10 класи, кілька груп) і хоче, щоб сайт став робочим ресурсом для всіх уроків, а не лише збіркою вправ:

1. **Структура за програмами.** Учень і вчитель знаходять свій курс, а в ньому — тему за номером уроку з календаря.
2. **Розбавити урок.** Діти не люблять слухати теорію поспіль. Потрібні короткі (3–7 хв) «відступи» посеред пояснення: щось покрутити, вгадати, посперечатись. Частина відступів — об'ємні сцени на three.js там, де об'єм пояснює краще за текст.
3. **Підтримати вчителя.** Календарний план кожного курсу і для кожної теми — план уроку на одну сторінку: мета, хід по хвилинах, цікавинка на старт, ресурси, питання для обговорення, домашнє завдання.

Усе лишається статичним, без реєстрації, без збереження даних, у тому ж стилі, що й зараз.

## Цілі

- Сайт відображає реальну структуру роботи вчителя: курси → теми з номерами, як у календарі. Учень знаходить свій урок за дві дії.
- Теми й ДЗ імпортуються з таблиць для Мрії; зміна календаря = перезапуск скрипта.
- Учитель відкриває одну сторінку перед уроком і знає, що робити, за 1 хвилину.
- Будь-який відступ запускається з проєктора (великі шрифти, веде вчитель) і на телефоні учня без окремих версій.
- Новий урок і учительська картка робляться копіюванням шаблонів, як у README.
- Three.js-сцени живуть окремими модулями, мають fallback без WebGL.
- Перші теми за розкладом зроблені повністю (учень + учитель), одна — із three.js-сценою.

## Не-цілі

- Жодного бекенду, акаунтів, збереження прогресу, аналітики.
- Не переписувати три наявні уроки; їх доповнюємо учительськими картками, бейджем «відступ» і новими номерами.
- Не робити систему збірки для сайту. Скрипт імпорту — інструмент розробника, запускається вручну в Node; сайт працює після `git push`.
- Не робити всі 520 тем: каркас + імпорт усіх тем як «заплановані» + 4 теми курсу ШІ повністю. Решту вчитель добиває за шаблоном.
- Серія three.js-інтерактивів для блоку 3D-графіки 9 класу — **наступний проєкт** з окремим дизайн-документом; тут лише закладається місце для неї.

## Анти-цілі

- Сцена «аби 3D». Кожна сцена має відповідати на питання «що тут видно об'ємно, чого не видно на малюнку».
- Відступ, що ламає урок: довше 7 хвилин, потребує реєстрації, встановлення чи швидкого інтернету.
- Учительська сторінка, яку треба читати 10 хвилин.
- Сцена, що вішає шкільний ПК без відеокарти або не відкривається на телефоні.
- Розбіжність між номером теми на сайті і в Мрії.

## Обмеження

- GitHub Pages, чистий HTML/CSS/JS. Three.js з CDN через `importmap`, версія зафіксована (`three@0.165.0`, jsdelivr).
- Інтерфейс, коментарі, тексти — українською; ідентифікатори коду — англійською.
- Шкільні ПК можуть бути без дискретної відеокарти; телефони — середні Android. Сцени: до ~5 000 вершин, `devicePixelRatio ≤ 2`, без постобробки, пауза анімації, коли вкладка/елемент не видимі.
- Без зовнішніх шрифтів; зображення лише в репозиторії.
- Доступність: усе керується клавіатурою; сцена має текстовий опис і кнопки керування.
- Папка `documents/` з таблицями — вхідні дані; її можна не публікувати (рішення вчителя; за замовчуванням лишається в репозиторії, бо там немає персональних даних).

### Дані

**`programs.js`** — довідник курсів, правиться руками:

```js
window.PROGRAMS = [
  { id: "ai", title: "Штучний інтелект і суспільство", level: "10–12 класи, основний / поглиблений рівень",
    authors: "Бородатюк А., Саута С.", grade: 10, groups: [],
    hours: { s1: 1, s2: 1 },               // год/тиждень по семестрах
    sources: ["шІ/ШІ_і_суспільство_І_семестр_Мрія.xlsx", "шІ/ШІ_і_суспільство_ІІ_семестр_Мрія.xlsx"] },
  { id: "inf9", title: "Інформатика. 9 клас", authors: "Ривкінд Й. Я. та ін.", grade: 9,
    groups: [{ name: "70 год", hours: { s1: 2, s2: 2 } }, { name: "група 22, 52 год", hours: { s1: 1, s2: 2 } }],
    sources: ["9 клас/Інформатика_9_клас_70год_І_семестр_Мрія.xlsx", "9 клас/Інформатика_9_клас_70год_ІІ_семестр_Мрія.xlsx"] },
  …
];
```

`sources` вказує скрипту, з яких таблиць (у порядку семестрів) брати теми; для `inf9` беруться лише 70-годинні, для `inf10deep` файл «уроки 21–48» не вказується.

**`data/<id>.js`** — генерується скриптом, по одному файлу на курс:

```js
window.TOPICS = window.TOPICS || {};
window.TOPICS.ai = [
  { num: 1,  semester: 1, title: "Штучний інтелект у нашому житті: основні поняття, історія розвитку, типи ШІ",
    homework: "Скласти ментальну карту «ШІ у моєму житті»." },
  …
  { num: 17, semester: 2, title: "Етика творчості з ШІ. Авторські права. Дипфейки та маніпуляції", homework: "…" },
];
```

Правила імпорту: `num` наскрізний за рік (ІІ семестр продовжує нумерацію І); префікс «Інструктаж з БЖД.» і «Правила поведінки та безпеки життєдіяльності…» вирізаються з назви (БЖД — окремий спільний урок `00-safety`); порожні рядки й технічний рядок «20 | | | …» ігноруються; текст ДЗ копіюється як є. Скрипт перезаписує `data/*.js` повністю і друкує зведення (курс, уроків на семестр), щоб помилку було видно одразу.

**`lessons.js`** — реєстр готових сторінок:

```js
window.LESSONS = [
  { folder: "00-safety", program: "all", label: "Вступне заняття", status: "ready", teacher: true, tags: [...] },
  { folder: "13-image-prompting", program: "ai", num: 13, status: "ready", teacher: true, tags: [...] },
  { folder: "12-ai-health-communication", program: "ai", num: 12, status: "ready", teacher: true, tags: [...] },
  { folder: "11-ai-presentations", program: "ai", num: 11, status: "ready", teacher: true, tags: [...] },
  { folder: "14-ai-video", program: "ai", num: 14, status: "ready", teacher: true, tags: [...] },

```

Назва й опис теми беруться з `data/<program>.js` за `num` (щоб назва на сайті завжди збігалась із календарем); `desc` у `lessons.js` — необов'язковий короткий опис інтерактиву. Тема без запису в `lessons.js` показується як «заплановано». `status`: `ready` | `draft`.

**Перейменування наявних папок** (рішення вчителя): `10-image-prompting` → `13-image-prompting`, `11-ai-health-communication` → `12-ai-health-communication`. Старі адреси перестають працювати; у старих папках лишається `index.html` з одним рядком «Урок переїхав» і `<meta http-equiv="refresh">` на нову адресу.

### Головна сторінка

Картки курсів: назва, клас, групи з годинами, лічильник «готово N тем із M». Фільтр класу (8, 9, 10) працює на рівні курсів. Клік відкриває розділ курсу (`index.html#ai`): список тем по порядку з номером, назвою з календаря, бейджем семестру; готові теми — як теперішні картки уроків з посиланням, заплановані — сірі без посилання. Спільний урок `00-safety` показується першим у кожному курсі.

### Календарний план учителя (`teacher/index.html`)

Перемикач курсів зверху. Таблиця: №, семестр, тема, ДЗ (з Мрії), статус, кнопки «План» і «Урок» (лише для готових). Під таблицею — «годин у плані: 35, уроків готово: 4». Для курсу з кількома групами — підпис із годинами кожної групи, без окремих таблиць. Зверху — коротка довідка з посиланням на README, як оновити теми (запустити скрипт) і як додати урок.

### Учительська картка (`lessons/<folder>/teacher.html`)

HTML за шаблоном `template/teacher.html`, підключає `lesson.css` + `teacher.css` + `teacher.js`. Розділи у фіксованому порядку:

1. **Шапка**: курс, номер і назва теми (підставляються з `data` за `program`+`num`), тривалість, кнопки «Відкрити урок» і «Режим проєктора».
2. **Мета і ключові ідеї** (3–5 тез).
3. **Хід уроку** — таймлайн масивом, `teacher.js` рендерить і перевіряє суму хвилин:
   ```js
   Teacher.timeline(45, [
     {min: 3,  kind: "hook",     title: "Цікавинка", text: "…"},
     {min: 10, kind: "theory",   title: "…", link: "index.html#theory"},
     {min: 6,  kind: "break",    title: "Відступ: рухи камери", link: "index.html#camera", projector: true},
     {min: 12, kind: "practice", title: "…", link: "index.html#quiz-tab"},
     {min: 7,  kind: "discuss",  title: "Обговорення", text: "…"},
     {min: 7,  kind: "wrap",     title: "Підсумок і ДЗ"}
   ]);
   ```
   `kind` задає колір; `link` відкриває вкладку уроку за `#id`; `projector: true` додає `?projector`.
4. **Цікавинка**: факт/історія/відео на 1–2 хв.
5. **Ресурси**: 2–4 відео (назва, канал, тривалість, з якої хвилини, мова), 1–2 статті/сервіси; стартові добірки для курсів ШІ, «Розумні плати» і STEM уже є в учителя (Tinkercad, AI Лабораторія Unicorn/IT Step, Дія.Освіта, Академія ШІ Google, збірники «STEM-школа», Scientix). Усі посилання перевірені, з датою перевірки.
6. **Питання для обговорення** (3–5).
7. **Домашнє завдання** — підставляється з Мрії за замовчуванням, можна переписати; **типові помилки** — необов'язково.

`@media print`: 1–2 сторінки А4 без кнопок.

### Відступи в уроці учня

Відступ — вкладка з `data-break="5"` (хвилини). `lesson.js`:
- бейдж «⏱ 5 хв» на кнопці вкладки й окремий стиль;
- адресовані вкладки: `#id` у URL відкриває вкладку; клік оновлює hash через `history.replaceState`; без hash — перша вкладка, як зараз;
- режим проєктора `?projector`: клас `projector` на `body` → базовий шрифт 20px, ширший `.wrap`, приховані «← Усі уроки» і футер, крупніші кнопки. Логіка вправ не змінюється;
- публічне API балів для власних міні-вправ: `Lesson.register(max)`, `Lesson.addScore(id)`, `Lesson.setScore(id, v)` (зараз внутрішні).

### Three.js-сцени

`assets/scene.js` — ES-модуль-обгортка:

```js
import { mountScene } from "../../assets/scene.js";
mountScene("#camera", {
  setup(ctx)  { /* ctx.scene, ctx.camera, ctx.renderer, ctx.el → state */ },
  update(ctx, state, dt) { /* кадр */ },
  controls: [ {label: "Наїзд", onClick(state){…}}, … ],
  describe: "Текстовий опис того, що відбувається у сцені"
});
```

Обгортка: рендерер (`antialias`, `pixelRatio ≤ 2`), resize за контейнером, пауза, коли вкладка не активна або елемент поза viewport, кнопки керування з клавіатури, перевірка WebGL **і** невдалого імпорту `three` → fallback `<figure>` зі статичним зображенням `assets/scenes/<name>.png` (або SVG) і текстом `describe`. `three` підключається в HTML уроку через `importmap` (jsdelivr, `three@0.165.0`). Сцени працюють лише з http(s) (Pages або локальний сервер), не з `file://`; решта сайту — як раніше. Сцена не рахує бали; перевірка поруч — звичайною вправою.

**Урок 13. Генерація та редагування зображень** (є). Перейменувати папку; учительська картка.

**Урок 11. Презентації та візуалізація з ШІ. Створення слайдів та інфографіки** (новий).
- Теорія: що ШІ робить добре (структура, чернетка, варіанти), що лишається людині (факти, акценти, «один слайд — одна думка»); формула запиту на презентацію.
- Відступи: «Виправ слайд» — поганий слайд із 6 типовими помилками, учень клікає на помилки (міні-скрипт, 5 хв); «Який графік?» (`Lesson.sort`); конструктор запиту на презентацію (за зразком уроку 13).
- Перевірка: вікторина «Що не так із запитом на слайди?».
- Three.js: ні (рішення автора: плоскі слайди, об'єм штучний).

**Урок 14. Створення відеоконтенту з ШІ. Анімація зображень. Генерація відео з тексту** (новий, флагман).
- Теорія: image-to-video / text-to-video / video-to-video; чому генератори потребують опису руху камери; обмеження (4–10 с, руки, текст, фізика); етика як місток до теми 17 (дипфейки).
- **Відступ зі сценою «Рухи камери»** (`scenes/camera-moves.js`, 5–7 хв): проста сцена (персонаж + декорації). Кнопки: наїзд (dolly in), від'їзд, панорама (pan), обліт (orbit), підйом (crane), зум, слідування (tracking). Під сценою — термін англійською/українською і фраза для промпту. Режим «вгадай рух»: сцена програє випадковий рух, учень обирає назву з 4 кнопок (міні-вікторина через `Lesson.register`). Що видно об'ємно: різницю між наїздом і зумом, між панорамою і обльотом.
- Інші відступи: «Яка техніка?» (сортування: image-to-video / text-to-video / video-to-video / не ШІ); конструктор промпту для відео.
- Перевірка: вікторина «Чому відео вийшло не таким?».
- Учитель: картка, ресурси, цікавинка (реальний перевірений випадок, коли ШІ-відео сплутали зі справжнім, і як розпізнали).

## Уточнення після перевірки будівельником

- `file://` і CDN: усе, крім сцен, працює з файлу; сцени — лише з http(s); fallback і на відсутність WebGL, і на невдалий імпорт.
- Браузери для сцен: з підтримкою `importmap` (Chrome/Edge 89+, Firefox 108+, Safari 16.4+); решта — fallback.
- Ресурси й цікавинки: будівельник перевіряє кожне посилання через вебпошук; неперевірене — плейсхолдер «перевірити», не вигадка.
- Зміни в `lesson.js` зворотно сумісні; три наявні уроки перевіряються вручну.
- «Вгадай рух» — окремий скрипт у сторінці уроку через публічне API балів.
- Fallback-зображення: PNG-скріншот або SVG.
- Сортування календаря завжди за `num`; дати не потрібні (вони в Мрії).

## Що вирішив автор (можна оскаржити)

- Теми імпортуються скриптом із таблиць для Мрії, а не правляться руками: єдине джерело правди, нуль розбіжностей із журналом.
- Скрипт імпорту — Node-скрипт у `scripts/`, запускається вручну; результат (`data/*.js`) комітиться, щоб сайт лишався статичним.
- Учительські матеріали — HTML із шаблону, не JSON/Markdown з рендером.
- Учительські сторінки публічні.
- Three.js з jsdelivr; при потребі переноситься в `assets/vendor/` однією правкою importmap.
- Режим проєктора — параметр `?projector`.
- Сцени не рахують бали.
- Курс `python` показується без класу, поки вчитель не вкаже.
