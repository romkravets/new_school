Лічильник range

Цикл for бере числа з range() і виконує тіло для кожного з них. Покрути повзунки, передбач послідовність і простеж цикл рядок за рядком: що стає з i та s.

Бали: 0 / 0

range(stop)

range(5) дає 0, 1, 2, 3, 4: починає з 0 і йде з кроком 1. Число stop не входить.

range(start, stop)

range(2, 6) дає 2, 3, 4, 5. Якщо start не менший за stop, послідовність порожня: range(5, 1) — нічого.

range(start, stop, step)

range(2, 10, 3) дає 2, 5, 8. Від'ємний step іде назад: range(10, 0, -3) — 10, 7, 4, 1. Крок 0 неможливий: ValueError.

Цикл for

Змінна циклу бере по черзі кожне значення з range, і для кожного значення виконується тіло циклу (рядки з відступом).

s = 0 for i in range(1, 5): s += i print(s) # 10: тіло виконалось для i = 1, 2, 3, 4
Пам'ятай: кількість проходів — це кількість чисел у range. Для range(1, 5) їх чотири (а не п'ять), бо stop = 5 не входить. Кількість можна порахувати так: (stop − start) для step = 1.

Лічильник range

Обери форму запису й крути повзунки: нижче одразу видно, які числа дає range. Бали тут не нараховуються: просто досліджуй, а потім передбачай.

Передбач послідовність

Які числа дає range? «Не знаю»: 0 балів і без втрат. Обов'язково прочитай «чому».

Трасування 1

Заповни, чому дорівнюють i і s наприкінці кожного проходу. Один бал за правильний рядок. «Показати відповіді» закриває таблицю з 0 балів за невирішені рядки.

s = 0 for i in range(1, 5): s += i

Трасування 2: з умовою

Тепер додаємо тільки парні числа. Для кожного проходу вкажи i, чи істинна умова, і значення s після проходу.

s = 0 for i in range(1, 7): if i % 2 == 0: s += i
