Проєкт «Миготіння світлодіода» на фізичній платі

Керуй вбудованим світлодіодом плати UNO, дізнайся, коли око перестає бачити миготіння, і знаходь помилки в скетчі.

Бали: 0 / 0

Плата UNO

Мікроконтролер ATmega328, 14 цифрових входів/виходів, 6 аналогових входів, живлення через USB. Вбудований світлодіод «L» під'єднано до піну 13.

Дві функції скетча

setup() виконується один раз на старті, loop() повторюється безкінечно.

Три команди

  • pinMode(13, OUTPUT) — пін працює як вихід;
  • digitalWrite(13, HIGH/LOW) — вмикає або вимикає;
  • delay(1000) — пауза в мілісекундах.

Код із лабораторної 1

int counter = 0; void setup() { Serial.begin(9600); // відкрити COM-порт pinMode(13, OUTPUT); // пін 13 — вихід } void loop() { digitalWrite(13, HIGH); // світлодіод увімкнено delay(1000); // 1000 мс = 1 с digitalWrite(13, LOW); // вимкнено delay(1000); counter++; Serial.println(counter); }
Пам'ятай: після кожної команди — крапка з комою ;, а Serial.begin(9600) має бути раніше за будь-який Serial.println.

Симулятор миготіння

Задай, як довго світлодіод світить і як довго вимкнений, та запусти скетч.

Коли око перестає бачити миготіння?

      
Зменшуй затримку, поки світлодіод не здаватиметься таким, що світить постійно. Тоді натисни кнопку.

      

        

          
          
          

        

      

      

      

      
Для затримок, коротших за ~20 мс, браузер не встигає показувати окремі спалахи, тому ми малюємо те, що бачить око: світло середньої яскравості.

    

  


  

    

      
Знайди помилку

      
У кожному скетчі є одна помилка. Клацни на рядок, де вона. Кнопки-рядки працюють і з клавіатури.
