Митниця типів

Ти працюєш митником. Вираз прибуває як декларація, а ти ставиш штамп: який тип матиме результат, чи Python його взагалі пропустить. Потім «вантаж» відкривають, і видно справжнє значення.

Бали: 0 / 0

Чотири штампи

ТипПриклад
int42, -7, 0
float3.5, 2.0, 1e3
str"3", 'abc'
boolTrue, False

Є ще п'ятий штамп: Помилка. Python зупиняє програму, а не вгадує, що ти мав чи мала на увазі.

Арифметика

/ — звичайне ділення, завжди float: 7 / 2 дає 3.5, а 10 / 5 дає 2.0.

// — ціле ділення (округлення вниз), % — остача, ** — степінь.

7 // 2 = 3, 7 % 3 = 1, 2 ** 10 = 1024.

Перетворення

int("42"), float("3.5"), str(42), bool(x).

int(3.99) відкидає дробову частину: 3. Але int("3.5") — помилка: рядок має виглядати як ціле.

round(x) округлює до найближчого цілого, а на «половинці» бере парне: round(2.5) = 2, round(3.5) = 4.

Де митник помиляється найчастіше

print("3" + "4") # 34 — рядки склеюються print("3" * 3) # 333 — рядок повторюється print(-7 // 2) # -4 — округлення вниз, не до нуля print(-7 % 3) # 2 — остача не буває від'ємною при додатному дільнику print(bool("False")) # True — непорожній рядок завжди істинний print(0.1 + 0.2) # 0.30000000000000004 — float зберігає наближення
Пам'ятай: спершу назви тип, потім рахуй значення. Більшість «дивних» результатів пояснює саме тип.

Пост: постав штамп

Для кожного виразу обери тип результату або «Помилка». Не впевнений чи не впевнена? Тисни «Не знаю»: 0 балів, але без втрат, і митниця покаже відповідь.

Передбач вивід

Що надрукує програма? Бал дає твоє передбачення. Кнопка «Перевірити запуском» (якщо Python у браузері доступний) лише показує справжній вивід.
