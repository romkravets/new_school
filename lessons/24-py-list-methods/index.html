Робот-комірник

Список — це полиця з ящиками, а методи — команди для робота-комірника. Одні команди переставляють ящики на місці, інші ще й щось повертають у руки. Передбач, як виглядатиме полиця.

Бали: 0 / 0

Метод змінює список на місці

Метод списку — це команда, яку виконують над самим списком: a.append(5). Список змінюється, а ось те, що метод повертає, буває різним: майже завжди це None (тобто нічого), а в pop, index і count — корисне значення.

КомандаЩо робить зі спискомЩо повертає
a.append(x)додає x в кінецьNone
a.insert(i, x)вставляє x перед позицією iNone
a.remove(x)видаляє перше входження x (немає — ValueError)None
a.pop() / a.pop(i)виймає останній елемент (або елемент i)цей елемент
a.sort()упорядковує на місціNone
a.reverse()розвертає порядок на місціNone
a.index(x)нічого не змінюєпозицію першого x
a.count(x)нічого не змінюєскільки разів x є в списку
a.extend(b)додає елементи b по одному в кінецьNone
a.clear()спустошує списокNone

Головна пастка: a = a.sort()

sort змінює список на місці й повертає None. Тому запис a = a.sort() упорядкує старий список, а потім запише в a саме None: полиці в a більше немає.

a = [3, 1, 2] a = a.sort() print(a) # None a.append(5) # AttributeError: 'NoneType' object has no attribute 'append'
Пам'ятай: remove прибирає лише перше входження, pop() без числа виймає останній ящик і віддає його, а a.sort() без присвоєння — правильний запис.

Робот-комірник

Перед кожною командою обери, як виглядатиме полиця після неї. Один бал за правильний крок. «Не знаю»: 0 балів і без втрат, робот усе одно покаже, що вийшло.
