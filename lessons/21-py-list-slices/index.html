Потяг-список

Список — це потяг: кожен вагон має номер з голови й номер з хвоста. Крути повзунки start, stop, step, бачи, які вагони потрапляють у зріз, і передбачай результат.

Бали: 0 / 0

Індекс

a = ["локомотив", "пошта", "купе"]. Нумерація з нуля: a[0] — локомотив, a[2] — купе.

Від'ємні індекси рахують з хвоста: a[-1] — останній вагон, a[-2] — передостанній.

Зріз a[start:stop]

Береться від start включно до stop не включно. Тож a[1:3] — вагони 1 і 2. Довжина зрізу — stop - start.

Пропущений start — з початку, пропущений stop — до кінця.

Крок a[start:stop:step]

a[::2] — кожен другий вагон. Від'ємний крок іде з хвоста: a[::-1] — потяг задом наперед.

Крок 0 не має сенсу: ValueError.

Дві різні поведінки

a = [10, 20, 30, 40, 50, 60] a[10] # IndexError: вагона з таким номером немає a[2:10] # [30, 40, 50, 60]: зріз без помилки, межі «підрізаються»
Пам'ятай: одиночний індекс поза межами — помилка, а зріз ніколи не дає помилки індексу: він просто бере те, що є.

Потяг на проєкторі

Під кожним вагоном: додатний індекс і від'ємний. Крути повзунки або став позначку «порожньо» (це пропущена частина, None). Підсвічені вагони потрапляють у зріз, цифра на них — порядок обходу.

Спробуй: a[1:4], a[-2:], a[::-1], a[4:1:-1], a[5:1] (порожній зріз) і крок 0.

Передбач зріз

Дано a = [10, 20, 30, 40, 50, 60]. Що дасть вираз? «Не знаю»: 0 балів і без втрат.
