Диспетчерська розвилок

Ти диспетчер: програма — колія зі стрілками. Дивись на значення змінних, веди поїзд по гілках і називай, який рядок надрукується. Потім збери таблицю істинності для and, or і not.

Бали: 0 / 0

Порівняння

== рівно, != не рівно, < > <= >=. Результат — bool: True або False.

Одне = присвоює, подвійне == порівнює. if x = 5: — синтаксична помилка.

Python дозволяє ланцюжок: 1 <= x <= 10.

and, or, not

A and B істинне, коли обидва True. A or B — коли хоч одне True. not A міняє значення.

Пріоритет: спершу not, потім and, потім or. Тож True and False or True дає True. Не впевнений чи не впевнена — став дужки.

Вкладеність

Тіло гілки може містити свій if. Усе, що з відступом, виконується лише разом з тією гілкою, у якій воно лежить.

Окремі if один під одним перевіряються всі. Ланцюжок if/elif/else — лише першу вдалу гілку.

if / elif / else

grade = 8 if grade >= 10: print("Високий") elif grade >= 7: print("Достатній") elif grade >= 4: print("Середній") else: print("Початковий")

Python йде зверху вниз, зупиняється на першій істинній умові й не дивиться далі. Тому порядок гілок має значення: починай з найвужчої (найвищої) умови.

Пам'ятай: else не має умови: він ловить усе, що не підійшло вище.

Трасування: який рядок надрукується?

Над кодом — значення змінних. Обери, що з'явиться на екрані. Після відповіді підсвітиться шлях, яким пройшла програма. «Не знаю»: 0 балів і без втрат.

Таблиця істинності

Клацай клітинку: «—» → True → False → «—». Заповни всі, натисни «Перевірити». «Показати відповіді» відкриє таблицю без балів.
