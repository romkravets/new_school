Зріж точно

Тепер навпаки: дано список і те, що має вийти. Запиши зріз a[start:stop:step], який дає саме цю ціль. Додатні й від'ємні індекси, крок, що розвертає: усе в ділі.

Бали: 0 / 0

Пам'ятка

a[start:stop:step]: start включно, stop не включно, пропущена частина означає межу списку, від'ємний індекс рахується з хвоста, від'ємний крок іде назад. Якщо крок від'ємний і start пропущено, зріз починається з останнього елемента.

Який зріз дав це?

Дано a = [10, 20, 30, 40, 50, 60]. Обери зріз, що дає показаний результат. «Не знаю»: 0 балів і без втрат.

Зріж точно

У всіх цілях список називається a. Запиши вираз, наприклад a[1:4]. Одиночний індекс не підійде: ціль це список. Якщо твій запис не довший за еталонний, отримаєш ★ (бонус, без додаткових балів). «Показати відповідь» відкриває еталон, але ця ціль уже без балів.
