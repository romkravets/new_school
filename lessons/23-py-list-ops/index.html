Склад списків

Списки можна склеювати, повторювати, шукати в них і порівнювати. А ще є підступна пастка: b = a не робить копії. Передбачай, перевіряй і дивись, на що вказують імена.

Бали: 0 / 0

+ та *

[1, 2] + [3] дає [1, 2, 3]: новий список, склеєний з двох.

[1, 2] * 3 дає [1, 2, 1, 2, 1, 2]. А [0] * 0 дає [].

in та len

3 in [1, 2, 3] — True: перевіряється наявність елемента. Якщо елемент у списку складніший (скажімо, рядок), in порівнює його цілком: "a" in ["abc"] — False.

len(a) — кількість елементів верхнього рівня: len([[1, 2], [3]]) дорівнює 2.

min, max, sum

min([4, 2, 8]) — 2, max — 8, sum — сума чисел.

sum([]) дорівнює 0, а min([]) і max([]) дають ValueError. Рядки порівнюються за символами: max(["10", "9"]) — "9".

Порівняння списків

Списки порівнюються поелементно зліва направо, як слова в словнику: перша відмінність вирішує.

[1, 2] < [1, 3] # True: 1 == 1, а 2 < 3 [1, 2, 3] < [1, 2] # False: довший список «більший», якщо початок збігається [1, 2] == [2, 1] # False: порядок має значення
Пам'ятай: + і * створюють нові списки, а ось b = a нічого не створює: це друге ім'я для того самого списку (вкладка «Пастка b = a»).
