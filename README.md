# Інтерактиви з інформатики

Статичний сайт для учнів і вчителя: календарні теми за курсами, інтерактивні уроки та короткі учительські плани. Працює на GitHub Pages без реєстрації, акаунтів і збереження даних.

- Головна сторінка: `https://romkravets.github.io/new_school/`
- Календарний план учителя: `https://romkravets.github.io/new_school/teacher/`
- Окремий урок: `https://romkravets.github.io/new_school/lessons/<папка>/`

## Структура

```
index.html                 курси та теми з календарних планів
programs.js                назви курсів, класи, групи й джерела
lessons.js                 реєстр готових інтерактивів
data/<курс>.js             теми та ДЗ, імпортовані з XLSX
documents/                 вхідні календарні плани для «Мрії»
scripts/import-mriya.mjs   імпорт XLSX у data/
teacher/index.html         календарний план учителя
assets/lesson.css          спільні стилі уроків
assets/lesson.js           вкладки, вправи, бали, режим проєктора
assets/teacher.css         стилі учительських планів і друку
assets/teacher.js          таймлайн і рендер учительської картки
assets/scene.js             обгортка для необов'язкових three.js-сцен
assets/scenes/              модулі сцен і статичні fallback-зображення
template/index.html        шаблон нового інтерактиву
template/teacher.html      шаблон учительського плану
lessons/                    готові уроки та картки вчителя
```

## Оновлення календарів

Файли в `documents/` — джерело тем і домашніх завдань. Замініть потрібний календар і виконайте з кореня репозиторію:

```sh
node scripts/import-mriya.mjs
```

Потрібні Node.js і стандартна утиліта `unzip` (є в macOS). Скрипт перезаписує `data/*.js`, наскрізно нумерує ІІ семестр, прибирає стандартний префікс БЖД, пропускає порожні рядки й друкує кількість тем за семестрами. Перевірте зведення перед комітом. Файли `data/` комітяться — для сайту не потрібні збірка чи сервер.

Джерела вказані в `programs.js`. Для 9 класу сайтом використовується послідовність 70-годинного плану; темп групи на 52 години ведеться в «Мрії». Дубль поглибленого плану для уроків 21–48 не імпортується. Клас групи Python не вказано, тому курс видно серед усіх курсів.

## Як додати інтерактив

1. Скопіюйте `template/` у `lessons/` і назвіть папку латиницею, наприклад `lessons/15-ai-audio`.
2. У `index.html` заповніть тему уроку, коротку теорію та вправи. Готові компоненти: `Lesson.quiz`, `Lesson.match`, `Lesson.sort`.
3. Додайте запис до `lessons.js`, наприклад:

   ```js
   {
     folder: "15-ai-audio",
     program: "ai",
     num: 15,
     status: "ready",
     teacher: false,
     tags: ["ШІ", "аудіо"]
   }
   ```

   Назва й номер уроку на головній беруться з `data/ai.js`; вони мають збігатися з календарем. Без запису в `lessons.js` тема лишається сірою як «Заплановано». `status` може бути `ready` або `draft`.
4. Для учительської картки скопіюйте `template/teacher.html` у папку уроку, підключіть правильний `data/<курс>.js` і заповніть `window.TEACHER_PLAN`.
5. Перевірте головну, урок і план учителя в браузері, потім закоміть і запуште зміни.

## Учительська картка й проєктор

У картці вчителя вкажіть цілі, етапи, цікавинку, ресурси, питання для обговорення й типові помилки. Сума `min` у `Teacher.timeline(45, [...])` має дорівнювати тривалості уроку: інакше сторінка покаже попередження. Домашнє завдання підставляється з календаря, його можна відредагувати перед друком.

На кнопці вкладки можна вказати `data-break="5"` — з'явиться бейдж тривалості. Посилання `index.html#quiz-tab` відкриває потрібну вкладку уроку. Додайте `?projector` для великого шрифту й прихованих навігаційних елементів, наприклад `index.html?projector#camera`.

Для власної вправи використовуйте публічне API балів:

```js
var scoreId = Lesson.register(5);
Lesson.addScore(scoreId);
Lesson.setScore(scoreId, 0);
```

## Three.js-сцени

Three.js завантажується з CDN лише для сторінки зі сценою. Потрібні сучасний браузер, WebGL і `http(s)` — наприклад, сайт на GitHub Pages або локальний сервер. Якщо імпорт чи WebGL недоступні, лишається локальне SVG-зображення й текстовий опис; решта інтерактиву продовжує працювати. Сцена «Рухи камери» для 14-го уроку — приклад модуля в `assets/scenes/`.

## Перегляд локально

`index.html` та звичайні уроки можна відкрити як файл. Для ES-модуля three.js потрібен локальний HTTP-сервер; наприклад:

```sh
python3 -m http.server 8000
```

Потім відкрийте `http://localhost:8000/`.
