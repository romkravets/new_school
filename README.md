# Інтерактиви з інформатики

Збірка навчальних інтерактивів. Кожен урок — окрема сторінка зі своїм посиланням, а головна сторінка показує список усіх уроків.

- Головна: `https://romkravets.github.io/new_school/`
- Урок: `https://romkravets.github.io/new_school/lessons/<папка-уроку>/`

## Структура

```
index.html            головна сторінка зі списком уроків
lessons.js            список уроків для головної (сюди дописуєш новий урок)
assets/lesson.css     спільний стиль для всіх уроків
assets/lesson.js      спільна логіка: вкладки, бали, вікторина, відповідність, сортування
template/index.html   заготовка нового уроку (не змінюй, а копіюй)
lessons/
  00-safety/                      Інструктаж з БЖД
  10-image-prompting/             Генерація та редагування зображень
  11-ai-health-communication/     ШІ для здоров'я та особистого розвитку
```

## Як додати новий урок

1. Скопіюй папку `template` у `lessons` і перейменуй її, наприклад на `12-chatbots`
   (латиницею, без пробілів, бо це буде частина посилання).
2. Відкрий `lessons/12-chatbots/index.html` і заміни:
   - назву, номер заняття й опис у шапці;
   - теорію в першій вкладці (звичайний HTML);
   - питання вікторини, відповідності й сортування у скрипті внизу файлу.
   Непотрібні вкладки просто видали разом з їхнім розділом `<section>`.
3. Допиши урок у `lessons.js`:
   ```js
   {
     folder: "12-chatbots",
     num: 12,
     title: "Назва уроку",
     desc: "Короткий опис",
     grade: "10–12 класи",
     grades: [10, 11, 12],
     tags: ["ШІ"]
   }
   ```
   `grades` визначає, у якому класі показувати урок: вкажи масив номерів класів, наприклад `[10, 11]`, або `"all"` для всіх класів. На головній сторінці учні можуть обрати клас у меню.
   Якщо замість «Заняття N» потрібен інший підпис, додай `label: "Вступне заняття"`.
4. Закоміть і запуш. За хвилину-дві урок з'явиться на сайті.

## Готові вправи

У будь-якому уроці після `<script src="../../assets/lesson.js"></script>` доступні:

| Вправа | Виклик | Що робить |
| --- | --- | --- |
| Вікторина | `Lesson.quiz("#id", [...])` | питання по одному, з поясненням після відповіді |
| Відповідність | `Lesson.match("#id", {options, items})` | до кожного пункту обрати варіант зі списку |
| Сортування | `Lesson.sort("#id", {choices, items})` | віднести кожен приклад до категорії |

Бали всіх вправ рахуються автоматично і показуються в шапці та в підсумку.
Формат даних є в коментарях у `template/index.html`. Головне правило: номер правильної відповіді `a` рахується з нуля.

Якщо уроку потрібне щось особливе (як конструктор промпту в 10-му занятті), пиши для нього власний скрипт прямо в його `index.html`.

## Публікація на GitHub Pages (один раз)

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save.

## Перегляд на своєму комп'ютері

Просто відкрий `index.html` у браузері: усе працює без сервера.
